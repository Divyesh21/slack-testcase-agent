
## Product Overview:
Editage is a platform enabling authors to submit manuscripts, request editing services, make payments, and interact with editors.

## Modules:
- Manuscript Submission
- Payments
- Multiple-Round Editing (MRE)
- Referral System
- User Profile

## User Types:
- Author
- Reviewer
- Editor
- Admin

## Key Business Rules:
- Authors must complete profile before submitting a manuscript.
- Manuscripts cannot be submitted without uploading a document.
- Editing services are enabled only after successful payment.
- Referral credits are awarded only after a referral completes their first order.

## Edge Cases:
- Author tries submitting without uploading a file.
- Payment is interrupted before redirection.
- Submission initiated before filling mandatory metadata.

## Test Case Style:
- Format: Markdown
- Include: Objective, Precondition, Steps, Expected Result
- Prioritize positive, negative, and boundary cases
